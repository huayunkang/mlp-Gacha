# Pony Roulette V2 · 实现与验收

更新：2026-09-13。此版本在现有 React / Vite、Worker、Static Assets、R2 项目上增量开发。没有重新初始化项目，没有创建线上 Cloudflare 资源。

## 已加入

- 原创玻璃扭蛋机、马蹄旋钮、指针拖动、旋转／掉落／打开演出；Full / Fast / Off，点击 Skip 或 Space 跳过。跳过只省略演出，首次网络下载仍需要完成。
- 系统减少动画偏好优先，低性能设备减少粒子。Rare+ 使用最多 16 个 Canvas 星星，低配置 6 个；不引入 3D 引擎或外站动画。
- 动态原生 Filter 抽屉、真实标签计数和复杂规则、开放过滤器确认、顶部警告、持久化选择；默认开启、可选择关闭的严格 Safe 内容保护。
- Character 搜索网格、Random Character、Random / Top Rated / Featured / Surprise Me；Surprise Me 随机一个允许角色和 solo / smiling / scenery / cute 主题。
- 6 级确定性稀有度；New / Duplicate ×N、Discovery Streak、全部发现图鉴、收藏、最近历史、Profile 和 6 项成就。
- IndexedDB 只保存发现元数据；轻量设置、收藏与最近 50 张历史继续兼容 V1 localStorage。首次读取时导入旧收藏和历史，不伪造旧版累计抽取次数：导入条目 count 为 0，Total Rolls 从 V2 开始统计。
- 可选低音量合成音效、可用设备上的短振动、缩略图模糊背景、作者署名、详情抽屉、标签分类和白名单标签抽取。
- Auto / Data Saver / High / Original；自动考虑小屏、2G 与 saveData。只预取下一张 metadata，不预取原图。
- 分享文字卡片／页面链接，Web Share 可用时调用系统分享；`?image=123` 恢复时服务端重新检查当前 Filter。恢复不增加抽取计数。
- 教程、PWA manifest / 本地图标 / shell Service Worker、离线提示、高级服务状态。Service Worker 不缓存 API 或图片二进制；已缓存图片离线可用性取决于浏览器 HTTP 缓存。

这些记录实际为 `system: true, public: false`，因此允许条件是 system **或** public。V2 第一阶段只获取系统列表，没有做社区任意 Filter 搜索或 Custom Filter 编辑器。

`GET /api/filters`：验证上游结构 → Cache API 六小时 → R2 元数据持久备份。缓存过期后按需更新；不是定时任务。上游失败时使用旧 R2 快照；无任何快照时返回网站 `Pony Roulette Safe`，内部 ID 0。失败结果在 Cache API 缓存五分钟，避免连续重试。

`GET /api/random?filter=100073&character=fluttershy&mode=random`：仅接受当前允许列表的 ID，转为上游 `filter_id`。复杂 Hidden 规则交给 Philomena 搜索引擎处理；不在浏览器猜测表达式含义。上游真实 `spoilered` 字段控制遮罩，字段缺失时保守遮罩。

**严格 Safe 内容保护默认开启，可在设置中明确确认后关闭。** 开启时保留 V1 的 `safe` 标签和严格内容标签规则；关闭后，随机与按图恢复都只依照当前允许的 Derpibooru Filter。无论设置如何，Filter ID 仍必须在实时目录允许列表中，系统删除／隐藏图片及 Filter 的 Hidden 规则仍会被拦截。无可用公开 Filter 时，网站回退到 ID 0 的 Safe 模式并强制开启严格保护。图鉴中不属于当前 Filter 的旧条目仍先遮罩，打开时重新检查。

## 稀有度公式

计算发生在随机取得图片以后，绝不按稀有度搜索。

```text
P = max(0, score)
  + min(500, max(0, faves) × 0.25)
  + (min(width, height) >= 2000 ? 25 : 0)

Common     P < 80
Uncommon   80 <= P < 250
Rare       250 <= P < 600
Epic       600 <= P < 1200
Legendary  P >= 1200
```

Harmony 优先于上表，必须同时满足：真实 `featured image` 标签、score ≥ 1500、Wilson score ≥ 0.98、faves ≥ 1000。缺失字段按不满足处理。没有承诺固定出现概率，也没有假称官方评级。Community Favorite 仅当真实 score ≥ 600；Featured 标识只由真实标签决定。

## 新 API 与缓存

- `/api/filters`：系统过滤器目录。
- `/api/random`：新增 filter / strict / surprise / 白名单 tag 参数，继续 no-store。
- `/api/metadata/:id?filter=...&strict=...`：在当前 Filter 与严格保护状态内查询指定图片，分享恢复和图鉴打开使用。
- `/api/image/:id`：必须使用允许的 filter 与 strict 参数；默认 large，`size=preview` 为缩略图，`size=saver` 优先 medium，`size=original` 为 full。边缘缓存按 Filter、严格状态和尺寸隔离。
- `/api/health`：原有接口，仅在高级设置主动读取。

限制仍包括正整数 ID、严格查询参数、同源浏览器请求、上游域名白名单、禁止重定向、图片签名验证、默认 8MB 上限、有限重试、退避和限流。Original 超出上限会提示错误，用户可切换 High / Saver。

## 已实际验证与边界

- 13 项自动测试通过，含真实 workerd + 本地 R2、Cache API、限流绑定；安全、四种图片 MIME、缓存命中、ETag、下载上限、上游失败、超时、退避、空结果、Filter 允许列表／转发／陈旧缓存／无缓存回退、稀有度和重复计数。
- 实际 Filter endpoint 返回上述 6 项，任意 ID 99999999 返回 400。
- 实际浏览器 Default 与 Everything 均抽图成功，Network 包含 `filter=100073` / `filter=56027`；22 条资源记录全部同源，没有 Derpibooru / derpicdn 浏览器直连。记录工具只存在隔离 QA 构建中。
- Full、Fast、Off、Space Skip、收藏、角色搜索、Filter 确认、分享 URL 刷新恢复已操作检查。隔离的固定图片测试已显示 DUPLICATE ×2；部署 dry-run 也通过，正确识别原有 R2 与限流绑定。Reduced Motion 与 offline 使用隔离测试脚本模拟浏览器能力；不是修改用户操作系统设置。
- 390×844、430×932、1920×1080、2560×1440 浏览器视口检查无横向溢出，主内容最大 1720px。手机结果模式压缩机器，图片优先。尚未在实体 Android / iPhone 上测量触觉、系统分享、安装 PWA 或持续帧率；不能把视口模拟称为真机 60fps 认证。
- 本地 `/api/health` 返回 `status: ok, derpibooru: reachable, r2: ok`。图片 172904 的 Saver 版本实际写入缓存，PNG，341707 bytes。云端 R2 尚未创建／部署，不能据此声称云端已验证。
- 生产首屏 JS 约 259KB、CSS 约 23KB（压缩前）；不包含抽到的图片，低于 1MB。无外部字体、角色头像集、GIF 或 Lottie 下载。

## 免费架构下的取舍

没有账号、数据库、VPS、Firebase、Supabase、金币、付费抽卡或签到任务。复用现有 R2 保存一份小型 Filter 快照；不新增 KV。Cloudflare 免费额度不是无限用量。

为控制流量与复杂度，预取只做 metadata；不做原图预下载、主色提取、复杂 3D 物理或离线图片库。分享优先文字卡片与链接，不重新上传艺术作品。图片大小上限继续 8MB。以上多数是轻量设计选择，并非 Cloudflare 强制禁止对应功能。

V2 部署目标为现有 Cloudflare Worker + Static Assets + R2。`server-node/` 保留作为 V1 备用参考，未扩展成完整 V2 服务；请用 Worker 方式测试 V2。

## 本地运行与下一步

```bash
npm install
npm run build
npm run dev:all
# 自动验收
npm test
npm run check:worker
```

需要本机 HTTP 代理时，在 PowerShell 设置自己的 HTTPS_PROXY 后运行 `npm run dev:proxy`，打开 `http://127.0.0.1:8788`。代理辅助启动器读取已构建产物，修改后须 build 并重启。

当前机器已有可用依赖；若 npm 不在 PATH，可将 `$env:TEMP\pony-tools` 加入 PATH 使用已有本地 npm shim。

下一步：先在本地体验；之后按 README 的 Cloudflare 步骤创建私有 `pony-images` Standard bucket、设置 `images/` 30 天生命周期，登录自己的 Cloudflare 账号并执行 `npm run deploy`。R2 开通流程和可能的计费信息由用户本人确认。V2 没有增加新 binding，也没有替用户部署。
