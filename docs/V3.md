## 最终实现

1. **Provider**：`derpibooru`、`trixiebooru`、`twibooru`，固定顺序串行回退。
2. **Derpibooru endpoint**：`/api/v1/json/search/images`；公开系统 Filter 为 `/api/v1/json/filters/system`。
3. **Trixiebooru 兼容性**：实现共享 Philomena Adapter 与独立开关，不假定 Filter ID 兼容。2026-09-14 实测其 API 路径从当前出口返回 HTTP 403 HTML Cloudflare challenge，因此不能称为当前完全可访问；该响应被识别为站点挑战并进入 Twibooru。
4. **Twibooru endpoint**：搜索 `/api/v3/search/posts`，按 ID `/api/v3/posts/:id`，响应分别解析 `posts` 与 `post`。
5. **Twibooru Random**：发送相同的 Pony Roulette 查询、`sf=random`、`per_page=3`、`filter_id=2`，再从通过二次校验且不重复的候选中随机选一张。
6. **Failover 测试**：测试确认主源成功时只发生一次 Provider 搜索；503 后按 Derpibooru → Trixiebooru；再次 403 challenge/503 后才访问 Twibooru。三个源全失败返回主题化 503。
7. **Safe Query**：`safe,-suggestive,-questionable,-explicit`。
8. **13+ Query**：`suggestive,-safe,-questionable,-explicit`。
9. **Adult All Query**：`(questionable OR explicit),-safe,-suggestive`。
10. **Explicit Only Query**：`explicit,-safe,-suggestive,-questionable`。Questionable 子模式为 `questionable,-safe,-suggestive,-explicit`。
11. **Clean**：追加 `-semi-grimdark,-grimdark,-gore,-grotesque`。
12. **Dark**：允许 `semi-grimdark` / `grimdark`，追加 `-gore,-grotesque`。
13. **Graphic**：不追加上述图形排除标签；Sexual Content 条件保持原值。
14. **Rating Adapter**：三个 Provider 分别拥有映射表；当前都从互斥的 `safe`、`suggestive`、`questionable`、`explicit` 标签映射，映射配置保持分源，后续可独立调整。
15. **Graphic Adapter**：三个 Provider 分别拥有映射表；`gore` / `grotesque` 优先映射 graphic，`semi-grimdark` / `grimdark` 映射 dark，其余确认过的图像映射 clean。
16. **Unknown Rating**：可能存在，例如没有 Rating 或同时存在多个 Rating 的异常元数据。
17. **Unknown 处理**：所有 Sexual 与 Graphic 模式都拒绝 unknown。查询命中后仍逐张标准化并用 `contentAllows` 二次检查。
18. **canonicalId**：Derpibooru 与其镜像 Trixiebooru 使用 `derpibooru:<id>`；Twibooru 有 Derpibooru location 时也使用该 ID，否则使用 `twibooru:<id>`。
19. **Twibooru 映射**：Adapter 读取 `locations[].location === "derpibooru"` 的 `id_at_location`；模拟真实结构的集成测试确认 Collection 去重有效。
20. **PicPony**：不作为 Provider，不抓网页。当前没有验证到稳定的按 ID 深链，因此暂未添加容易失效的主动入口。
21. **Network**：`publicPony` 删除全部 representations；主图、缩略图、模糊背景和预加载只返回 `/api/image/:provider/:id`。本地真实抽取与代理图片验证均为本站请求。Provider Page / Source 仅由用户主动点击。
22. **R2**：生产 `wrangler.toml` 无 R2 binding，运行只需要 Worker Static Assets + Cache API。代码保留可选 `PONY_IMAGES` 兼容路径。
23. **Health**：`/api/health` 返回 `status`、三个 Provider 的最近状态与细节、`active`、`mediaCache`、`checkedAt`。它读取被动状态缓存，不并发探测图库。
24. **限流与条款**：Twibooru 文档标明搜索 10 次/分钟、单图 60 次/分钟；因此只作最后备用，并读取 `X-RL`、`X-RL-Remaining`、`X-RL-Reset`。实测搜索返回 `X-RL: 10` 与 `X-RL-Reset`，未返回 Remaining；缺失值按 unavailable 处理，不误判为 0。没有抓取 PicPony。
25. **后续操作**：一般使用者只需打开部署地址。开发者可运行 `npm install`、`npm run build`、`npm test`、`npm run check:worker`，再用 `npm run deploy` 发布。
