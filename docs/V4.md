# Pony Roulette V4

在现有 V3 上增量升级，复用现有机器、动画、独立内容分级、公开 Filter、顺序备用源、稀有度、IndexedDB 图鉴、PWA 和同源代理。

## 收藏库

- 图鉴、收藏与历史可以组合搜索图片 ID、标签、作者与来源名称。
- 支持按最近记录、评分或稀有度排序；同值按最近记录排序。
- 每页展示 24 张，缩略图懒加载，减少大量发现记录的 DOM 和图片请求。
- 设置中可导出和导入收藏 JSON。导入合并去重，已有收藏优先，最多 1000 张；文件上限 5 MB。
- 备份只包含收藏 metadata，不包含图片二进制、完整发现日志、设置或成人确认状态。
- 导入重新计算评级与规范 ID、重建来源页面，丢弃外部图片和来源地址，不信任备份里的图片 URL。导入后的图片仍走本站代理和服务端校验。成人内容未经确认不会下载缩略图。

## 容错

Twibooru HTTP 200 即使 X-RL-Remaining 为 0，也保留这次成功结果。之后的 HTTP 429 仍由现有顺序备用机制处理，不增加重试或并行源请求。

所有 provider JSON metadata 在解码前限制为 1 MB。即使上游缺少 Content-Length，流式读取也执行上限，超限进入备用源。

## 免费部署与限制

沿用 Cloudflare Workers Free + Static Assets + Cache API。没有新增数据库、R2 或收费服务。动态请求受免费计划每日请求量、CPU 等配额限制；缓存可能被淘汰，不能承诺图片永久离线可用。R2 当前未启用。

## 验证与本地使用

Node.js 22 以上：`npm ci`、`npm test`、`npm run build`、`npm run check:worker`。本地完整代理运行 `npm start`，访问终端显示的本地地址；生产发布 `npm run deploy`。

自动化覆盖收藏搜索、排序、非破坏性合并、备份内容验证、上游超大响应、备用源最后配额响应，以及既有内容过滤、SSRF、故障切换和错误处理。真实移动设备的触摸与帧率测试仍需设备实测。
